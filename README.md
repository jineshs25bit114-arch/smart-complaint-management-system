# Smart Complaint Management System

A web-based complaint management system designed to help students submit complaints and enable college staff/admin to manage, track, and resolve them efficiently.

## Features

- Student complaint submission
- Complaint tracking
- Admin dashboard
- Complaint status management
- Priority-based complaints
- Department management
- Reports and analytics
- Student and admin login

## Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite
- Git & GitHub

## Project Structure

- `app.py` - Main Flask application
- `index.html` - Main web page
- `database.db` - SQLite database
- `requirements.txt` - Python dependencies
- `static/css/style.css` - Website styling
